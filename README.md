# Cisco Packet Tracer — Network Infrastructure & Services Labs

## 📌 Overview

This repository contains two network infrastructure projects developed using Cisco Packet Tracer as part of my learning journey in **Network Systems Administration, Networking, and Cybersecurity**.

The projects focus on enterprise network design, network segmentation, device connectivity, firewall configuration, and the implementation of essential network services in simulated environments.

## 🖧 Project 1: Enterprise Network Infrastructure & Security Lab

### Description

An enterprise network infrastructure simulation featuring routers, switches, VLANs, IP addressing, and an ASA 5505 firewall.

### Main Topics

- Network topology design
- Router and switch configuration
- VLANs and network segmentation
- IP addressing and connectivity
- Firewall configuration and network security
- Communication between network devices

### Objectives

- Understand enterprise network architecture.
- Practice network device configuration.
- Explore network segmentation and security.
- Test connectivity in a simulated environment.

## 🌐 Project 2: IoT Network Infrastructure & Services Lab

### Description

A network simulation integrating VLANs, IoT devices, and essential network services, including DNS, FTP, and DHCP.

### Main Topics

- VLAN configuration
- IoT device integration
- DHCP for automatic IP address assignment
- DNS for name resolution
- FTP for file transfer
- Network connectivity and service configuration

### Objectives

- Configure and test common network services.
- Integrate IoT devices into a simulated network.
- Understand how network segmentation supports infrastructure organization.
- Practice troubleshooting and connectivity testing.

## 🛠️ Technologies & Tools

- Cisco Packet Tracer
- Networking fundamentals
- TCP/IP and IP addressing
- VLANs
- Routing and switching
- Network security and firewall concepts
- DNS, DHCP, and FTP
- Internet of Things (IoT)

## 🎯 Learning Outcomes

These projects provide practical experience in network design, configuration, and troubleshooting. They help strengthen my understanding of network infrastructure, network services, and security concepts as I continue developing my skills in IT systems administration and cybersecurity.

## 📂 Project Files

Each project includes its corresponding Cisco Packet Tracer simulation file (`.pkt`), allowing the network topology and configuration to be explored.
